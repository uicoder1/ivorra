# IVORRA — Premium Brand Showcase Website

A single-page brand showcase website for **IVORRA** ([https://ivorra.in/](https://ivorra.in/)), an Indian fashion jewellery brand.

## Overview

This website serves as a brand showcase highlighting IVORRA's contemporary collections, artisan heritage, and verified retail distribution across leading Indian marketplaces (Amazon India, Flipkart, JioMart, Meesho, and ivorra.in).

## Key Sections

1. **Hero**: Editorial jewellery lifestyle campaign presentation.
2. **About IVORRA**: Authentic brand story, Indian craftsmanship, and founding origin (South Delhi, 2024).
3. **Our Collections**: Curated architecture covering Earrings & Jhumkis, Necklaces & Sets, Modern Mangalsutras, Anklets & Payals, Chains & Pendants, and Velvet Storage Cases.
4. **Marketplace Distribution**: Corporate brand showcase connecting customers directly to verified storefronts.
5. **The IVORRA Standard**: Four core design pillars and curated product gallery.
6. **Contact & Corporate Footer**: Direct store access and business/investor collaboration inquiries.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React + custom inline brand SVGs

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production (e.g. Vercel deployment)
npm run build
```
